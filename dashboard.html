웹사이트 및 용어 설명

이 웹사이트는 무엇인가요?

이 웹사이트는 산불 위험을 예측하는 모델의 성능을 시각적으로 비교하고 분석하기 위해 개발되었습니다. 다양한 예측 모델(예: LightGBM, Transformer, 예측 산불)이 산불 발생 가능성을 얼마나 정확하게 예측하는지, 그리고 어떤 지표에서 강점을 보이는지 한눈에 파악할 수 있도록 돕습니다.

사용자는 이 대시보드를 통해 각 모델의 정확도, 정밀도, 재현율, F1-Score를 비교하여, 어떤 모델이 특정 상황에서 더 적합한지 판단하는 데 도움을 받을 수 있습니다.

모델 설명

  • LightGBM (Baseline): 기본적인 머신러닝 모델로, 빠르고 효율적인 학습이 특징입니다. 다른 모델들의 성능을 비교하는 기준점(baseline)으로 사용됩니다.
  • Transformer: 자연어 처리 분야에서 뛰어난 성능을 보이는 모델 구조로, 시계열 데이터나 복잡한 패턴 인식에 활용될 수 있습니다.

성능 지표 설명

  • 정확도 (Accuracy): 전체 예측 중에서 올바르게 예측한 비율입니다. (예: 산불이 발생한다고 예측했는데 실제로 발생했고, 산불이 발생하지 않는다고 예측했는데 실제로 발생하지 않은 경우)
  • 정밀도 (Precision): 모델이 '산불 발생'이라고 예측한 것 중에서 실제로 산불이 발생한 비율입니다. (오탐을 줄이는 것이 중요할 때 유용)
  • 재현율 (Recall): 실제 산불이 발생한 경우 중에서 모델이 산불이 발생한다고 올바르게 예측한 비율입니다. (실제 산불을 놓치지 않는 것이 중요할 때 유용)
  • F1-Score: 정밀도와 재현율의 조화 평균입니다. 두 지표의 균형을 고려할 때 사용됩니다.

이 지표들은 모델이 산불 위험을 얼마나 효과적으로 감지하고 분류하는지 평가하는 데 중요한 역할을 합니다.

기술 및 최적화 과정 설명

이 프로젝트는 최신 머신러닝 기술을 활용하여 산불 발생 위험을 예측합니다. 단순히 데이터를 학습하는 것을 넘어, 모델이 최상의 성능을 낼 수 있도록 데이터를 정교하게 가공하고, 자동화된 최적화 과정을 적용했습니다.

1. 주요 사용 기술 및 데이터 처리

  • 예측 모델 (LightGBM, RandomForest):
    • LightGBM: 매우 빠르고 효율적인 모델로, 대규모 데이터에서도 좋은 성능을 보여 기본 모델로 사용됩니다.
    • RandomForest: 여러 개의 '의사결정 나무'를 모아 예측 정확도를 높이는 모델입니다. 개별 나무의 단점을 집단 지성으로 보완하는 방식입니다.
  • 데이터 가공 및 변환 (Feature Engineering):

    모델이 잘 학습하려면 원본 데이터를 '정제'하고 '가공'하는 과정이 필수적입니다.

    • 주기적 데이터 변환: '월'이나 '시간'처럼 반복되는 데이터는 특별한 처리가 필요합니다. 예를 들어, 12월과 1월은 숫자로는 멀리 떨어져 있지만 실제로는 가깝습니다. 이런 관계를 모델에 알려주기 위해 데이터를 사인(sin), 코사인(cos) 값으로 변환하여 '순환'하는 특징을 명확히 했습니다.
    • 범주형 데이터 변환 (Label Encoding): '강원', '경북'과 같은 문자 데이터를 모델이 이해할 수 있도록 '0', '1'과 같은 숫자 코드로 변환하는 작업을 거쳤습니다.
  • 데이터 불균형 해소 (SMOTE 기법):

    산불은 발생하지 않는 날이 훨씬 많기 때문에, 데이터는 '산불 발생'과 '발생 안 함' 사이에 심각한 불균형을 이룹니다. 모델이 소수의 '산불 발생' 데이터를 제대로 학습하지 못하는 것을 방지하기 위해 SMOTE라는 기술을 사용했습니다. 이는 '산불 발생' 데이터와 유사한 가상의 데이터를 만들어 모델이 충분히 학습할 수 있도록 돕는 기술입니다.

2. 모델 성능 최적화 (하이퍼파라미터 튜닝)

모델은 여러 가지 설정값(하이퍼파라미터)에 따라 성능이 크게 달라집니다. 예를 들어, RandomForest 모델의 '나무 개수'나 '최대 깊이' 같은 값들입니다. 최적의 설정값을 찾는 과정은 마치 요리사가 최고의 맛을 내기 위해 재료의 비율을 정밀하게 조절하는 것과 같습니다.

  • 자동 최적화 도구 (Optuna):

    이 프로젝트에서는 Optuna라는 자동 하이퍼파라미터 튜닝 도구를 사용했습니다. 사람이 직접 수많은 설정값을 테스트하는 대신, Optuna가 수백 번의 자동화된 실험을 통해 모델의 예측 정확도를 가장 높이는 최적의 설정값 조합을 스스로 찾아냅니다. 이 과정을 통해 각 모델이 자신의 잠재력을 최대한 발휘할 수 있도록 정교하게 튜닝되었습니다.

이러한 기술들을 통해 산불 위험을 더 정확하게 예측하고 예방하는 데 필요한 정보를 제공합니다.

과거 산불 발생 추세 분석 (선형성)

실제 과거 산불 발생 건수의 추세를 분석하여 예측 모델의 일관성을 시각화합니다. 파란색 점은 일별 산불 발생 건수를, 붉은색 선은 이 데이터의 선형 회귀 추세선을 나타냅니다. 이 추세선은 시간이 지남에 따라 산불 발생 빈도가 어떻게 변화하는지 보여주며, 우리의 예측 모델이 이러한 실질적인 패턴을 따르고 있음을 증명하는 중요한 근거가 됩니다.
