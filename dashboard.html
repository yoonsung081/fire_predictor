웹사이트 및 용어 설명

이 웹사이트는 무엇인가요?

이 웹사이트는 산불 위험을 예측하는 모델의 성능을 시각적으로 비교하고 분석하기 위해 개발되었습니다. 다양한 예측 모델(예: LightGBM, Transformer, 예측 산불)이 산불 발생 가능성을 얼마나 정확하게 예측하는지, 그리고 어떤 지표에서 강점을 보이는지 한눈에 파악할 수 있도록 돕습니다.

사용자는 이 대시보드를 통해 각 모델의 정확도, 정밀도, 재현율, F1-Score를 비교하여, 어떤 모델이 특정 상황에서 더 적합한지 판단하는 데 도움을 받을 수 있습니다.

모델 설명

  • LightGBM (Baseline): 기본적인 머신러닝 모델로, 빠르고 효율적인 학습이 특징입니다. 다른 모델들의 성능을 비교하는 기준점(baseline)으로 사용됩니다.
  • Transformer: 자연어 처리 분야에서 뛰어난 성능을 보이는 모델 구조로, 시계열 데이터나 복잡한 패턴 인식에 활용될 수 있습니다.

성능 지표 설명

  • 정확도 (Accuracy): 전체 예측 중에서 올바르게 예측한 비율입니다. (예: 산불이 발생한다고 예측했는데 실제로 발생했고, 산불이 발생하지 않는다고 예측했는데 실제로 발생하지 않은 경우)
  • 정밀도 (Precision): 모델이 '산불 발생'이라고 예측한 것 중에서 실제로 산불이 발생한 비율입니다. (오탐을 줄이는 것이 중요할 때 유용)
  • 재현율 (Recall): 실제 산불이 발생한 경우 중에서 모델이 산불이 발생한다고 올바르게 예측한 비율입니다. (실제 산불을 놓치지 않는 것이 중요할 때 유용)
  • F1-Score: 정밀도와 재현율의 조화 평균입니다. 두 지표의 균형을 고려할 때 사용됩니다.

이 지표들은 모델이 산불 위험을 얼마나 효과적으로 감지하고 분류하는지 평가하는 데 중요한 역할을 합니다.

산불 예측 모델의 작동 원리

본 산불 예측 시스템은 과거 산불 데이터를 기반으로 미래의 산불 발생 위험을 예측합니다. 예측 과정은 크게 데이터 준비, 모델 학습, 예측 수행의 세 단계로 구성됩니다.

1. 데이터 준비 (Feature Engineering)

산불 발생에 영향을 미치는 다양한 요인들을 수집하고 분석 가능한 형태로 가공합니다. 주요 데이터는 다음과 같습니다:

  • 시간 정보: 산불 발생 연도, 월, 일, 시간, 요일 등
  • 공간 정보: 산불 발생 시도, 시군구 등 지리적 위치
  • 원인 정보: 산불 발생의 주요 원인 분류

이러한 원시 데이터는 머신러닝 모델이 학습할 수 있도록 수치형 특성(Feature)으로 변환됩니다. 예를 들어, 월이나 시간 같은 주기적인 정보는 사인(sin) 및 코사인(cos) 변환을 통해 모델에 효과적으로 전달됩니다.


import pandas as pd
import numpy as np

# 예시 데이터 로드 및 특성 생성
df = pd.DataFrame({
    '발생일시_년': [2023, 2023],
    '발생일시_월': [10, 11],
    '발생일시_일': [15, 20],
    '발생일시_시간': [14, 10],
    '발생장소_시도': ['강원', '경북'],
    '발생장소_시군구': ['강릉', '안동'],
    '발생원인_구분': ['실화', '부주의']
})

df['발생일시'] = pd.to_datetime(df['발생일시_년'].astype(str) + '-' + df['발생일시_월'].astype(str) + '-' + df['발생일시_일'].astype(str))
df['day_of_week'] = df['발생일시'].dt.dayofweek
df['month_sin'] = np.sin(2 * np.pi * df['발생일시_월']/12)
df['month_cos'] = np.cos(2 * np.pi * df['발생일시_월']/12)
df['hour_sin'] = np.sin(2 * np.pi * df['발생일시_시간']/24)
df['hour_cos'] = np.cos(2 * np.pi * df['발생일시_시간']/24)

# 범주형 특성 인코딩 (실제 모델 학습 시 사용된 인코더를 재사용)
from sklearn.preprocessing import LabelEncoder
le_sido = LabelEncoder().fit(['강원', '경북', '충남', '전북']) # 예시
le_sigungu = LabelEncoder().fit(['강릉', '안동', '부여', '남원']) # 예시
le_cause = LabelEncoder().fit(['실화', '부주의', '기타']) # 예시

df['발생장소_시도'] = le_sido.transform(df['발생장소_시도'])
df['발생장소_시군구'] = le_sigungu.transform(df['발생장소_시군구'])
df['발생원인_구분'] = le_cause.transform(df['발생원인_구분'])

print(df[['발생일시_년', '발생일시_월', '발생일시_시간', 'day_of_week', 'month_sin', 'month_cos', 'hour_sin', 'hour_cos', '발생장소_시도', '발생장소_시군구', '발생원인_구분']].head())
